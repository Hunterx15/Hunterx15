## Featured Projects

### EdgeFlow — API Gateway
> A resilient, production-grade API gateway for managing services, routes, and traffic across backend systems.

**Tech:** `Node.js` `Express` `PostgreSQL` `Redis` `Docker` `React`

**Highlights**
- JWT-based authentication with API key management and role-based access
- Redis-backed response caching, circuit breakers, and weighted load balancing
- Sliding-window rate limiting and request routing across services
- Real-time monitoring and analytics dashboard for the request pipeline
- Load tested to ~20ms average latency, 6.9k req/s peak throughput, over 2.2M requests processed

[Repository](https://github.com/Hunterx15/edgeflow) · [Live Demo](https://edge-flow-orcin.vercel.app)
